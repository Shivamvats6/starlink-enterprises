# Starlink Enterprises — Website + Admin

React 18 + Vite + TypeScript + Tailwind + GSAP frontend (`frontend/`) and a Laravel 12 REST API (`backend/`, an overlay for a fresh Laravel install).

## Status

| Part | State |
|---|---|
| Frontend (public site + admin UI) | Built. `npm run build` and `tsc` pass. Browser-checked against the built-in mock API (login, validation, project save, draft hidden from public, contact → lead). |
| Backend (Laravel overlay) | Written and `php -l` syntax-checked **only**. It has not been installed, migrated or run (Packagist was unreachable in the build sandbox). Run `php artisan test` after installing. |

## Run the frontend now (no backend needed)

```bash
cd frontend
npm install
npm run dev          # VITE_USE_MOCK=true in .env
```
Admin: `/admin` — demo login `admin@starlink.test` / `admin123` (mock mode only; data lives in your browser's localStorage).

## Install the backend

```bash
composer create-project laravel/laravel api "^12.0" && cd api
php artisan install:api                       # installs Sanctum + routes/api.php
cp -R ../backend/* .                          # overlay: overwrites routes/api.php, routes/web.php, bootstrap/app.php
cat ../backend/.env.additions >> .env         # then edit DB + mail values
php artisan key:generate
php artisan migrate --seed                    # baseline categories, services, banner, legal pages (no fake data)
php artisan storage:link
php artisan starlink:create-admin you@company.com "Your Name"   # prompts for a 12+ char password
php artisan serve                             # http://localhost:8000
php artisan test
```
Then in `frontend/.env` set `VITE_USE_MOCK=false` and restart `npm run dev` (Vite proxies `/api`, `/sanctum`, `/storage`).

## Production notes
- Serve frontend and API on the same site (e.g. `example.com` + `example.com/api` via the web server) or on sibling subdomains; set `SESSION_DOMAIN`, `SANCTUM_STATEFUL_DOMAINS`, `CORS_ALLOWED_ORIGINS`, `FRONTEND_URL`, `APP_DEBUG=false`, `SESSION_SECURE_COOKIE=true`.
- Auth is Sanctum cookie sessions — no tokens in localStorage.
- Social/SEO: the SPA sets titles/meta client-side. Crawlers and link-preview bots that do not run JS need prerendering or a server-rendered meta layer (e.g. prerender service or Laravel-rendered `<head>` for `/projects/{slug}`).
- `/sitemap.xml` and `/robots.txt` are generated by Laravel; proxy them from the public domain.
- Back up the database and `storage/app/public` regularly.
